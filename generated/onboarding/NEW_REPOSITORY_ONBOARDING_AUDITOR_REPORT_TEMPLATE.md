# New Repository Onboarding — Auditor Report Template

## Scope and Authority
Repository identity, URL, assessment time/run ID, EMS hashes, Hayes registry hash.

## Classification and Applicability
Classification snapshot; unknown fields; applicable, NOT_APPLICABLE, and APPLICABILITY_UNRESOLVED controls.

## Results
PASS, FAIL, WARNING, INSUFFICIENT, HUMAN_REVIEW, NOT_IMPLEMENTED, EXECUTION_ERROR; evidence/provenance; exceptions.

## Completeness
State COMPLETE or PARTIAL. Unsupported and human-review controls remain visible.
