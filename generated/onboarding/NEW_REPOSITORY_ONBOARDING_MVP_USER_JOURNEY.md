# New Repository Onboarding MVP User Journey

Input: OscarMackJr/example-new-repository.

DISCOVER: snapshot GitHub identity; inaccessible metadata routes to HUMAN_REVIEW.
REGISTER: propose stable controlled ID; human authority allocates it.
CLASSIFY: record metadata; UNKNOWN security values stay UNKNOWN.
CALCULATE_APPLICABILITY: create separate new-target snapshot; historical freezes stay immutable.
RESOLVE_EVIDENCE: map each control to repository, CI, organization, service, or human evidence.
BUILD_ASSESSMENT_PLAN: freeze identity, classification, authority hashes, registry support, evidence requirements.
EXECUTE: reuse immutable batch runtime with local path override.
ADJUDICATE: preserve PASS, FAIL, WARNING, INSUFFICIENT, HUMAN_REVIEW, NOT_IMPLEMENTED, APPLICABILITY_UNRESOLVED, EXECUTION_ERROR.
PERSIST_EVIDENCE: store snapshots, requests, results, review queue, manifest, certification.
REPORT: show complete or partial outcome without hiding unsupported controls.
